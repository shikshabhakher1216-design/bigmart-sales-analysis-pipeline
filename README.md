# 🛒 BigMart Sales Analysis & Forecasting Pipeline

An end-to-end data pipeline and interactive analytics project built on the BigMart Sales dataset, featuring data cleaning, Exploratory Data Analysis (EDA), MySQL database integration, an interactive Streamlit web application, and a Power BI dashboard.

---

## 🛠️ Project Structure & Key Files

* **`Bigmart_EDA.ipynb`**: Exploratory Data Analysis, missing value imputation, and feature engineering.
* **`Bigmart_App.py`**: Interactive Streamlit web application for real-time sales visualization and predictions.
* **`Bigmart_mysql_db.ipynb`**: Python pipeline to structure and load cleaned sales data into a MySQL relational database.
* **`Bigmart_dashboard.pbix`**: Interactive Power BI report for business intelligence and sales performance monitoring.
* **`cleaned_bigmart.csv`**: The processed dataset ready for web app and database integration.

---

## 🧰 Tech Stack

* **Programming:** Python, SQL
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Streamlit, MySQL Connector
* **Database:** MySQL
* **BI Tool:** Power BI
